Location Graph — model prototype PROTOTYPE · THROWAWAY

The question this answers: do the settled Connection rules produce the navigable world we expect? Rules encoded: locations keep free implicit navigation (parent + children + siblings — top-level locations are not siblings of each other); an authored Connection between a pair replaces that pair's implicit link; Connections are one-way or two-way with an optional AI travel hint; unreachability is checked by following the directed graph from every starting location. Everything below — the canvas and the tables — is computed from one pure rules module, not drawn by hand.

Override: Market → Player's House ("hole in the fence")

Market and the House are siblings, so they'd connect both ways for free. The authored one-way Connection replaces that pair's implicit link — you can slip through the fence, but getting back means going around through the Village or Tavern.

Portal loop: Cave → Moon Sanctum → Village

Two one-way Connections between unrelated trees. From the Sanctum the Cave is simply never offered — no prompt text forbids it; the candidate list just doesn't contain it.

Plain link: Village ⇆ Forest ("along the muddy trail")

A two-way Connection joining two top-level regions that would otherwise be islands. One record, both directions, one shared travel hint.

Unreachable: Abandoned Shrine

It has an outgoing Connection to the Forest but nothing leads to it from any starting location, so the canvas badges it. (The author probably meant a two-way link — or a secret.)
