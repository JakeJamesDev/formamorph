# 💬 Bugs and Suggestions
<!-- keywords: ticket status, track my ticket, known issues, roadmap, upvote an idea, dev response, planned features, what data is sent, ask a question, community help, unanswered, me too -->

Use the **Feedback** window to report a bug, suggest something or ask a question.

> You must log in to use the **Feedback** window. See [Your Account](Account).

## How to Report a Bug or Suggest Something
<!-- keywords: feedback, issue, problem, error, broken, crash, idea, feature request, contact, developer, glitch, support ticket, tell the devs, wishlist, send a complaint, propose improvement, get support, something went wrong -->
<!-- route: feedbackHub -->

1. Log in.
2. On the main menu, select the round **Feedback** button at the bottom left.
3. Open the **Bugs**, **Suggestions** or **Questions** tab.
4. Select **Report a Bug**, **Suggest Something** or **Ask a Question**.
5. Fill in **Title**, **Category** and the description.
6. Select **Send Report**, **Send Suggestion** or **Post Question**.

In a game, **Send Feedback** in **More Actions** (`...`) opens the form directly. See [The Feedback Window](#the-feedback-window).

## The Feedback Window
<!-- route: feedbackHub -->

Select the round **Feedback** button at the bottom left of the main menu. It shows when you are logged in.

| Tab | What it holds |
|---|---|
| **Bugs** | Your bug reports, or all of them with **All Reports**. **Report a Bug** opens the form. Only you and the team reply to your report. The tab opens on **Unresolved**. |
| **Suggestions** | Everyone's suggestions, or yours with **Mine**. **Suggest Something** opens the form. Anyone can reply and vote. The tab opens on **Still Open**. |
| **Questions** | Everyone's questions, or yours with **Mine**. **Ask a Question** opens the form. Anyone can reply, and a vote says you have the same question. The tab opens on **Unanswered**, sorted by **Most Voted**. While you type a title, **Similar Questions** lists up to 5 matches. |

Sort a list by **Newest**, **Oldest** or **Recently Active**. **Suggestions** and **Questions** also sort by **Most Voted**.

You can also read the **Suggestions** and **Questions** boards at [formamorph.ai/feedback](https://formamorph.ai/feedback), with no account. Sign in there to vote or reply. Bug reports stay in the app.

A bug report includes your app version, platform and system. Nothing about your worlds or saves goes with it. The form keeps an unsent draft.

### Statuses

Staff set each item's status. Replies show in the item's thread, under **Bugs**, **Suggestions** or **Questions**.

| Kind | Statuses |
|---|---|
| Bug | **Open**, **Needs Info**, **Confirmed**, **Pending Release**, **Fixed**, **Won't Fix** or **Duplicate** |
| Suggestion | **Open**, **Considering**, **Planned**, **Pending Release**, **Declined** or **Added** |
| Question | **Open**, **Answered** or **Closed** |

- **Pending Release** means the change is done and comes in the next update.
- A closed question takes no more replies.
- Staff can also lock a suggestion or a question. A lock stops replies and edits.

### Accepted Answers

On your own question, select **Accept Answer** on the reply that solved it. Staff can do the same on any question.

- The question becomes **Answered**.
- The reply gets an **Accepted** mark.
- The reply also shows again under the question, so readers see it first.

Select **Clear Answer** to undo the pick. The question goes back to **Open**, but a closed question stays **Closed**.

If the author edits the accepted reply, the text under the question changes too. The question goes back to **Open** with no answer in two cases:

- The reply is deleted.
- Staff change the question to a bug or a suggestion.

### Thread Links
<!-- keywords: link a thread, thread number, hash number, refer to a suggestion, duplicate, see also, feedback url -->

Every bug, suggestion and question has a number, such as **#23**. It shows beside the title and in the list. The website address of a thread uses the same number: `formamorph.ai/feedback/23`.

To link another thread in a report or a reply, type `#` and its number, or paste its website address. The link shows as a chip with the thread's type, number, title and status. Select the chip to open that thread.

| You type | What shows |
|---|---|
| `#23` | A chip for thread 23 |
| `https://formamorph.ai/feedback/23` | The same chip |
| `` `#23` `` or a code block | Plain text, as typed |

A thread you can't read, or one that was deleted, shows as **Unavailable thread** with its number and no title. On the website, a link to a bug report shows the same way, because bug reports stay in the app.

### Listing Links
<!-- keywords: link a world, link an entity, link a listing, share a creation, community link, paste a listing address -->

To link a world, entity, dictionary or prompt, paste its website address in a report or a reply. The address looks like `https://formamorph.ai/community/world/…`. The link shows as a chip with the listing's image, title and kind.

In the app, select the chip to open the listing in **Community Creations**. The **Feedback** window closes first. On the website, the chip opens the listing's page.

A listing that is hidden, waiting for review or deleted shows as **Unavailable listing**, with no title. An address in code, between backticks or in a code block, stays plain text.

### Mentions
<!-- keywords: mention a player, at sign, at username, tag someone, notify a player, unknown user, mention limit, too many mentions -->

To mention a player, type `@` and their username in a report, a question, a suggestion or a reply. Names ignore letter case. For a name with spaces, type `_` in place of each space.

The mention shows as a chip with the player's image and name. Select the chip to open their profile. On the website it opens their profile page.

| You type | What shows |
|---|---|
| `@lantern_keeper` | A chip with that player's image and name |
| `@` and a name with no account | **Unknown user**, without the name you typed |
| `` `@lantern_keeper` `` or a code block | Plain text, as typed |

On a suggestion or a question, a mention adds the thread to that player's feedback badge until they open it. Their later replies badge them too. Take the mention out, and the badge goes with it. On a bug report, a mention links but never badges.

[Listing comments](Community-Creations#comments) show mentions, thread numbers and listing links as chips too. A mention in a listing comment sends no alert.

### Suggestions While You Type
<!-- keywords: autocomplete, suggest a name, suggest a thread, find a player, find a thread number, at sign list, hash list -->

When you type `@` and a letter in a report, a reply or a listing comment, a list of players opens. Players who already posted in the thread come first. In a reply, `@` alone lists those players. When you type `#` and a number or a word, a list of threads you can read opens.

- Press the arrow keys to move, then press **Enter** or **Tab** to insert the pick. You can also select a row.
- Press **Escape** to close the list without inserting anything.
- Text in code, between backticks or in a code block, gets no list.

On the website, the `#` list shows only suggestions and questions.

### Mention Limits

Each post can mention a limited number of players:

| Account | Mentions per post |
|---|---|
| Player | 5 |
| Moderator or developer | 10 |
| Admin | No limit |

A repeat of one name counts once, and a mention of yourself counts for nothing. A post over the limit is refused with a message that names the limit. Your text stays in the box, so remove a name and send it again.
