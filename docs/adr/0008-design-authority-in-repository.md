# Keep Formamorph's design authority with its components

The repository design guide and live component showcase are the authoritative references for Formamorph UI, including prototypes. Keeping examples tied to production components reduces drift between sessions and between approved designs and implementation; an external design canvas is not required to maintain a second authoritative representation.

All app surfaces share visual foundations, with layouts and density suited to their purpose. Agents verify established patterns against the showcase; new visual patterns require user approval in app context, including their mobile form. This preserves room for layout exploration without treating a prototype request as permission to change the app's visual identity.
